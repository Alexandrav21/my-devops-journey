# Bandit Level 3 -> 4

## Goal
Find the password stored in a hidden file.

---

## Thought Process


I started by listing files with ls and saw an entry called inhere. To check what it was, I ran ls -l, which shows a detailed listing including file types and permissions. This confirmed that inhere is a directory.

I then moved into it using cd inhere. Running ls inside the directory didn’t show anything, which suggested the contents might be hidden. I then ran ls -la, which lists all files including hidden ones, and this revealed the file ...Hiding-From-You.

After finding it, I used cat to read its contents and get the password.

---

## Commands Used
```bash
ls
ls -l
cd inhere
ls
ls -la
cat ...Hiding-From-You
```
