## Thought Process
I listed all files with `ls` and saw a file named `-`. At first glance it looks like a normal filename, but - has a special meaning in Linux commands and is often treated as standard input.

When I tried `cat -`, it didn’t work as expected because of that special meaning. To treat `-` as an actual filename, I had to be explicit about its path. Using `cat ./-` tells the system to read the file in the current directory named `-`, which worked.
