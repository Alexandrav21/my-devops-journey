# Bandit Level 5 -> 6

## Goal
Find the password stored in a file somewhere under the inhere directory with the following properties:
- human-readable
- 1033 bytes in size
- not executable

---

## Thought Process
I started by listing files with `ls` and found the `inhere` directory. I moved into it using `cd inhere` and ran `ls -la` to explore its contents. There were multiple subdirectories, which meant manually checking each one would be slow.

Since the file had specific properties (size, type, and readability), I decided to use the find command. To better understand how to use it, I checked `man find`.

I then used:

- `-type f` to search for files only
- `-size 1033c` to match files that are exactly 1033 bytes

This narrowed it down to a single result: `./maybehere07/.file2`.

Although the goal also mentions "human-readable" and "not executable", the size filter was enough to uniquely identify the file in this case.

I then used `cat` to read the file and retrieve the password.

---

## Commands Used
```bash
ls
cd inhere
ls -la
man find
find -type f -size 1033c
cat ./maybehere07/.file2
```
