# Bandit Level 4 -> 5

## Goal
Find the password stored in the only human-readable file in the inhere directory.

---

## Thought Process
I listed files with `ls` and found the inhere directory, then moved into it using `cd inhere`. 
I ran `ls -l`a to see all files and noticed multiple files with similar names like -file00, -file01, etc.

Since the goal specifies a human-readable file, opening each file one by one with `cat` would be inefficient. Instead, I used the `file` command, which identifies the type of each file.

Running `file ./*` applies the file command to all files in the current directory. The `./` ensures the filenames are treated correctly (especially since they start with -), and `*` selects all files.

This quickly showed that only -file07 is ASCII text (human-readable), while the others are just data. 
I then used `cat` on that file to get the password.

---

## Commands Used
```bash
ls
cd inhere
ls -la
file ./*
cat ./-file07
```
